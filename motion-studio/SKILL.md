# Motion Studio

把內容變成幾十秒的動畫。動畫本身是程式碼，所以可以只改一個字、一個數字或一段時間，其餘不動。

能做：文字、數字跳動、長條圖、折線圖、清單、圖形、箭頭、圖片的進退場動畫與轉場；16:9、9:16、1:1、4:5。

做不到：3D 與運鏡、寫實影片、真人、AI 生成畫面、配音與背景音樂。

1. 要 3D、運鏡、配樂：改用 `remotion-studio`（如果有這個 skill；公司內使用要付 Remotion 授權費）。
2. 要寫實畫面、真人、配音：直接說做不到，建議把 MP4 匯出後拿去影片剪輯軟體加。

## 檔案

| 路徑 | 用途 |
|---|---|
| `assets/engine.html` | 播放器＋編輯器（不要手改內容，改分鏡就好） |
| `scripts/build.py` | 分鏡 → 發佈用的 index.html 與 spec.json |
| `scripts/render.py` | 分鏡 → MP4、GIF、靜態檢查圖 |
| `templates/` | 三個範本：說明動畫、動態圖表、直式步驟導覽 |
| `references/spec-format.md` | 分鏡格式完整說明，寫分鏡前先讀 |

## 流程

### 1. 問清楚（缺什麼才問）

1. 給誰看、在哪播（全員會議、簡報裡、LinkedIn、手機直式）。
2. 大概多長（預設 15～30 秒）。
3. 畫面比例：沒講就依播放地點推：簡報用 16:9，社群直式用 9:16，貼文用 4:5 或 1:1。
4. 素材：使用者附了報告、數據、圖片就從裡面取，不要自己編數字。

### 2. 寫分鏡

1. 從 `templates/` 挑最接近的範本，複製到工作目錄改，不要從零寫。
	1. `explainer.json`：16:9 說明動畫（標題、前後對比數字、步驟、結尾）。
	2. `chart.json`：16:9 動態圖表（結論數字、折線走勢、橫條比較）。
	3. `walkthrough.json`：9:16 步驟導覽（每步一張截圖＋圈選）。
2. 格式照 `references/spec-format.md`。
3. 分鏡規則：
	1. 一幕只講一件事。圖表那一幕的標題直接寫結論（「成長主要來自外銷」），不寫「各通路營收」。圖表內容的取捨照 `diagram-readability`（如果有這個 skill）。
	2. 每幕 3～6 秒。文字要讀得完：經驗值是每秒 4～5 個中文字，再加 1.5 秒停留。
	3. 同一幕的元素錯開 0.2～0.6 秒進場，先出標題，再出主角。
	4. 一幕最多一個搶眼的效果（`pop`、`count`、`draw` 擇一）；全片轉場統一用一兩種。
	5. 留邊：16:9 離邊至少 60px；9:16 上下各留 120px 給社群平台的介面。
	6. 字級下限（以 1280 寬或 720 寬為準）：內文 32px、標籤 20px。
	7. 色票 4～6 色，元素用色票名稱引用。深色背景上每個元素都要有顏色，對比要夠。
	8. 使用者的截圖放 `image` 的 `src`（data URI）。大圖先用 PIL 縮到長邊 1600px、存成 JPEG 品質 85 再轉 data URI。

### 3. 自己先看一次

每幕挑主角都出來之後的時間點出靜態圖，合成一張看：

```bash
python3 scripts/render.py spec.json checks/ --stills 2.5,6,10.5,14 --scale 0.6
```

檢查文字有沒有超出框、有沒有重疊、深淺對比、留邊。改一輪就好，不要反覆截圖。

### 4. 發佈成可編輯的頁面

```bash
python3 scripts/build.py spec.json out/
```

用 Artifact 工具發佈：`file_path` 是 `out/index.html`，`files` 是 `{"spec.json": "out/spec.json"}`，`capabilities` 是 `{"artifact": {}}`，`icon` 用 `film`。

頁面上使用者可以：

1. 播放、拖進度條、按空白鍵播放暫停。
2. 點畫面上的元素直接拖位置，拖右下角改大小（按住 Shift 等比例）、方向鍵微調。
3. 時間軸：點幕切換、拖幕的右緣改秒數、拖刻度移動時間；下方每個元素一條，拖整條移動出場時間、拖深色右緣改進場長度、拖灰色左緣改退場時間。
4. 右側面板：改文字、數字、數據、顏色、字級、效果、節奏；加元素、加圖片、複製、刪除、上下層；新增、複製、排序、刪除幕；改畫面比例、色票。
5. 復原、重做（Ctrl+Z）。
6. 「儲存」把修改存回頁面（只有使用者本人或有編輯權限的人能存）。不能存的時候用「複製分鏡」，把 JSON 貼回對話。

回覆時一句話說明頁面是什麼，提醒可以直接在頁面上改、改完按儲存，要影片檔就跟 Claude 說「匯出 MP4」。

### 5. 用講的改

1. 頁面可能已經被使用者改過並儲存，所以先讀最新版：Artifact 工具 `action: "read"`、`url` 是那個頁面、`path: "spec.json"`，用它存下來的檔案改。
2. 只改被要求的欄位（「第二幕慢一點」就加長那一幕的 `duration`、把元素的 `in.start` 往後推），不要順手重排其他東西。
3. 重新 build，發佈到同一個頁面：同一個對話用同一個 `file_path`；不同對話傳 `url`。

### 6. 匯出 MP4、GIF

1. 先讀頁面最新的 spec.json（同第 5 步）。使用者貼了 JSON 就把它寫成檔案用。
2. 匯出：

```bash
python3 scripts/render.py spec.json 影片名稱.mp4            # 16:9 → 1920×1080
python3 scripts/render.py spec.json 影片名稱.mp4 --scale 1  # 原尺寸，比較快
python3 scripts/render.py spec.json 影片名稱.gif --scale 0.6 --fps 15
```

3. 用 SendUserFile 給使用者，說明長度和尺寸。
4. 匯出只能在對話裡做，頁面本身沒有匯出按鈕；使用者問到就這樣說明。

## 環境與實測紀錄

1. 匯出需要 Python 的 playwright、Chromium、ffmpeg。先跑 `python3 -c "import playwright"` 和 `ffmpeg -version`。
	1. Chromium 沒裝而且裝不起來（網路受限）時，跟使用者說這次只能給頁面、不能出影片檔，不要改用其他方式繞。
2. 速度實測：16.5 秒、1920×1080、30fps，約 50 秒算完。超過 60 秒的片子先用 `--scale 1` 試。
	1. GIF 實測：15 秒、9:16、`--scale 0.6 --fps 15`，檔案約 480KB。GIF 色數有限，漸層和照片會有色帶，要畫質就給 MP4。
3. 頁面「儲存」實測可用（手機上也可以）：修改會寫回頁面的 spec.json，成為同一個 Artifact 的新版本，換裝置開同一個連結看到的是新版。
4. 匯出時連不到 Google Fonts，會改用系統的 Noto Sans CJK TC，和頁面上的 Noto Sans TC 是同一個字族。
5. 在本機直接開 index.html 時，主控台會出現讀不到 spec.json 的錯誤，正常；頁面會改用內嵌的分鏡。
6. 動畫是逐格跳到指定時間截圖，影片節奏不受電腦快慢影響。
